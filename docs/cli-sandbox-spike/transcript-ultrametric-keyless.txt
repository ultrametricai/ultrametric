$ npx -y ultrametric@0.4.1 --help
Usage: ultrametric [options] [command]

Company setup guidance and records for your project.

Options:
  -v, --version                output the version number
  --json                       Print a versioned JSON result; errors are JSON on
                               stderr.
  --no-json                    Use text output even when settings default to
                               JSON.
  --data-dir <directory>       User home for settings, logs, and data (or
                               ULTRAMETRIC_DATA_DIR).
  --environment <environment>  API and login environment; local records stay in
                               the selected data directory. (choices:
                               "production", "staging", default: "production")
  -h, --help                   display help for command

Commands:
  auth                         Log in, check status, or log out.
  init [options]               Install the Ultrametric documentation skill in a
                               project for Codex and Claude Code.
  process [options] [id]       Find guides and open hosted process runs.
  context                      Read and save hosted company context through the
                               API.
  understand [options]         Prepare a local profile with the legacy offline
                               guide.
  companies                    Validate, save, and retrieve local company
                               profiles.
  assess [options]             Give the active agent a project assessment guide,
                               rubric, and JSON template.
  assessments                  Save and retrieve local project assessments.
  actions                      Record the actions the user has chosen.
  arena                        Read vendor ratings and cited evidence directly
                               from ProductArena.
  config                       Manage settings shared across all project
                               directories.
  logs                         Inspect local command diagnostics.
  doctor                       Show diagnostic information.

Start here:
  ultrametric init                             Set up this project for your agent
  ultrametric process list                     Find available processes
  ultrametric process open company-profile --json  Start or resume company work
  ultrametric context get --json                Find hosted companies and records
  ultrametric auth login                       Log in

Use ultrametric <command> --help for options.
(exit 0)
