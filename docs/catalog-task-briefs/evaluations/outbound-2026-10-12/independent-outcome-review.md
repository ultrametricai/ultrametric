Its missing-personalization case receives a Boolean flag; it does not parse the actual message placeholders. The cadence has no executable scheduler. Provider webhooks, durable cross-campaign suppression, external CRM mutation and calendar booking were not tested. Duplicate-row detection rejects the changed input; it does not demonstrate a general deduplication workflow.

A company's public contact listing alone does not prove outreach eligibility or product fit. The simulation records are explicitly marked synthetic and are kept separate from the real-research and fictional-input ledgers.

## Method and publication

Both arms used the same natural prompt, frozen fictional source facts, factual-answer policy, model, effort, service tier and prospective resource ceilings. The operator inspected the control before starting UM. The local catalog contains extra selected standalone mappings, so this is not an exact production catalog-visibility test. The candidate was unpublished; marketplace installation, remote dashboard ingestion and production release are separate work.

[Metadata](metadata.json) records actual elapsed native time, tokens, tool activity, candidate/source hashes and the prospective reset-guard addendum. Repeated cached input contributes to the gross token totals. Token totals are workload observations, not financial cost or quality scores.

Private originals remain unchanged. The public derivatives redact unnecessary individual names, business contact addresses and a local synthetic run identifier; [the redaction ledger](publication-redactions.json) identifies original and published hashes without disclosing the removed tokens. Distinct opaque email labels preserve duplicate-check behavior. All source bytes and unredacted output bytes remain exact, executable filenames have an inert `.txt` suffix, and every archived file is hashed in [the manifest](artifact-manifest.json). Raw account/configuration data and authenticated catalog snapshots are excluded.
