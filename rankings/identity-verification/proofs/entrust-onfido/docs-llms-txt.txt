# Entrust Identity Verification Documentation

> Entrust Identity Verification is a comprehensive API and SDK platform for identity document verification, biometric checks, watchlist screening, and fraud detection. Customers integrate via REST API (v3.6 current) and native SDKs (Web, iOS, Android, React Native, Flutter), orchestrating verification flows through Workflow Studio.
